# gdrive-sync 설치 안내 (받는 분용)

이 문서는 gdrive-sync 를 처음 설치하는 분을 위한 안내입니다.
Windows 기준으로 설명하며, 약 20~30분 정도 걸립니다.

전체 과정은 3단계입니다:

1. **프로그램 설치** — Python + Git 설치 후 명령어 한 줄
2. **Google 인증 키 발급** — 본인 Google 계정으로 credentials.json 만들기 (최초 1회)
3. **초기 설정** — 동기화할 폴더 지정

---

## 1단계. 프로그램 설치

### 1-1. Python 설치

1. https://www.python.org/downloads/ 에서 최신 버전 다운로드
2. 설치 첫 화면에서 **"Add python.exe to PATH" 체크박스를 반드시 체크**하고 Install Now
3. 설치 확인: 시작 메뉴에서 `cmd` 를 실행하고 아래 입력

```bash
python --version
```

`Python 3.x.x` 가 나오면 성공.

### 1-2. Git 설치

프로그램 설치와 업데이트에 필요합니다.

1. https://git-scm.com/download/win 에서 다운로드
2. 설치 중 옵션은 전부 기본값 그대로 "Next" 만 눌러도 됩니다

### 1-3. gdrive-sync 설치

`cmd` 창에서 (Python·Git 설치 후 **새로 연** 창이어야 합니다):

```bash
py -m pip install git+https://github.com/GYcodeAI/gdrive-sync.git
```

> `pip install ...` 이 아니라 `py -m pip install ...` 로 시작하는 이유:
> PC에 파이썬이 여러 개 설치돼 있어도 항상 같은 파이썬에 설치되게 하기
> 위해서입니다. "git 실행 파일을 찾을 수 없다"는 오류가 나면 1-2단계 Git
> 설치 후 cmd 창을 새로 열어 다시 실행하세요.

설치 확인:

```bash
py -m gdrive_sync --version
```

(`gdrive-sync, version ...` 이 나오면 성공. 이후 단계의 `gdrive-sync ...`
명령이 "배치 파일이 아닙니다"라고 나오는 PC에서는 똑같이
`py -m gdrive_sync ...` 형태로 쓰면 됩니다 — 붙임표(-)가 아니라 밑줄(_))

## 2단계. Google 인증 키(credentials.json) 발급

이 프로그램은 **본인의 Google 계정**으로 Drive 에 접근합니다. 이를 위해
Google Cloud Console 에서 무료로 "OAuth 클라이언트"를 하나 만들어야 합니다.
어렵게 들리지만 클릭 몇 번이면 됩니다. 비용은 전혀 들지 않습니다.

### 2-1. 프로젝트 만들기

1. https://console.cloud.google.com 접속 → Google 계정으로 로그인

> **카드 등록 창이 떠도 등록하지 마세요.** 처음 접속하면 "무료 체험 시작" /
> "$300 크레딧" 안내가 뜨면서 결제 카드를 요구할 수 있는데, 이건 유료 기능용
> 무료 체험 가입이고 **우리가 쓸 기능과 무관합니다**. 닫기/건너뛰기 하면 되고,
> 프로젝트 생성·OAuth 발급은 카드 없이 전부 무료입니다.

2. 상단의 프로젝트 선택 드롭다운 → **새 프로젝트**
3. 프로젝트 이름: `gdrive-sync` (아무거나 가능) → **만들기**

### 2-2. Drive API 켜기

1. 왼쪽 위 삼선(줄 3개) 메뉴 → **API 및 서비스** → **라이브러리**
2. 검색창에 "Google Drive API" 입력 → **Google Drive API** 클릭 → 파란 **사용** 버튼
   (이미 켜져 있으면 "API 사용 설정됨"이라고 표시됩니다)

### 2-3. Google 인증 플랫폼 — 앱 정보 등록

> 안내 영상이나 오래된 블로그에 나오는 "OAuth 동의 화면" 메뉴는
> **"Google 인증 플랫폼"** 으로 이름과 구성이 바뀌었습니다. 아래가 현재 화면 기준입니다.

1. 상단 검색창에 `Google 인증 플랫폼` 입력 → **Google 인증 플랫폼** 클릭
   (또는 삼선 메뉴 → **API 및 서비스** → **OAuth 동의 화면** — 같은 곳으로 이동합니다)
2. 처음이면 "아직 구성되지 않음" 안내와 함께 **시작하기** 버튼이 보입니다 → 클릭
3. 단계별로 입력:
   - **앱 정보**: 앱 이름 `gdrive-sync`, 사용자 지원 이메일 = 본인 이메일 → 다음
   - **대상**: **외부(External)** 선택 → 다음
   - **연락처 정보**: 본인 이메일 → 다음
   - 정책 동의 체크 → **만들기**
4. 완료되면 왼쪽에 **개요 / 브랜딩 / 대상 / 클라이언트 / 데이터 액세스** 메뉴가 생깁니다

### 2-4. 테스트 사용자에 본인 추가

1. 왼쪽 메뉴 → **대상**
2. **테스트 사용자** 섹션 → **+ Add users** → 본인 Gmail 주소 입력 → 저장

### 2-5. OAuth 클라이언트 만들기 (credentials.json 다운로드)

1. 왼쪽 메뉴 → **클라이언트** → 상단 **+ 클라이언트 만들기**
2. 애플리케이션 유형: **데스크톱 앱** 선택, 이름은 그대로 → **만들기**
3. 생성 직후 뜨는 창에서 **JSON 다운로드** 클릭
   - 창을 그냥 닫았다면: **클라이언트** 목록에서 방금 만든 이름 클릭 →
     오른쪽 **JSON 다운로드** 버튼

### 2-6. 파일 배치

다운로드된 파일(`client_secret_xxxx.json`)의 이름을 `credentials.json` 으로
바꾸고, 아래 폴더에 넣습니다:

```
C:\Users\<내계정>\.gdrive_sync\credentials.json
```

`.gdrive_sync` 폴더가 없으면 새로 만드세요. (탐색기 주소창에
`%USERPROFILE%` 입력 → 새 폴더 `.gdrive_sync` 생성)

### 2-7. (권장) 앱을 프로덕션으로 게시

위 상태("테스트 중")로도 동작하지만, **로그인이 7일마다 만료**되어 매주
재인증해야 합니다. 이를 피하려면:

1. 왼쪽 메뉴 → **대상** → 게시 상태 "테스트 중" 아래의 **앱 게시** 버튼 → 확인
   (게시되면 이 자리에 "프로덕션 단계 / 테스트로 돌아가기"라고 표시됩니다)
2. 이후 로그인 시 "Google 에서 확인하지 않은 앱" 경고가 나오면
   **고급 → gdrive-sync(안전하지 않음)으로 이동** 을 눌러 진행하세요.
   본인이 직접 만든 앱이므로 안전합니다.

## 3단계. 초기 설정 및 첫 동기화

**새로 연** `cmd` 창에서 순서대로:

> **"...은(는) 내부 또는 외부 명령... 배치 파일이 아닙니다" 오류가 나면**:
> ① cmd 창을 닫고 새로 열어 다시 시도 → ② 그래도 안 되면 모든 명령에서
> `gdrive-sync` 대신 `py -m gdrive_sync` 를 쓰세요 (예: `py -m gdrive_sync init`).
> 동작은 완전히 같습니다. 주의: 이때는 이름에 붙임표(-)가 아니라 밑줄(_)입니다.

```bash
gdrive-sync init
```

이 명령은 **질문을 5개 던집니다** — 각 질문에 답을 입력하는 것이지,
질문 화면에 다음 명령어를 치는 것이 아닙니다. `[대괄호]` 안은 기본값이라
그냥 **Enter** 만 눌러도 됩니다:

| 질문 | 추천 답 |
|---|---|
| 동기화할 로컬 폴더 경로 | 원하는 PC 폴더 입력 (예: `D:\업무폴더`), 모르겠으면 Enter |
| 구글드라이브 상의 폴더 이름 | Drive 에 만들/이미 있는 폴더 이름 (예: `업무폴더`) |
| 충돌 해결 정책 | Enter (1번 newer_wins 추천) |
| 삭제 정책 | Enter (1번 trash 추천) |
| 동시 전송 파일 수 | Enter |

`✓ 설정 저장` 이 나오면 성공. 답을 잘못 입력했으면
`gdrive-sync init --force` 로 처음부터 다시 하면 됩니다.

```bash
gdrive-sync auth
```

브라우저가 열리면 본인 Google 계정으로 로그인하고 **허용**을 누릅니다.

```bash
gdrive-sync config --edit
```

설정 파일이 열리면 동기화할 로컬 폴더와 Drive 폴더를 지정합니다.
(전달한 사람에게 예시 설정을 받아 붙여넣는 것이 가장 쉽습니다)

미리보기(실제 전송 없음)로 확인:

```bash
gdrive-sync sync --dry-run
```

문제없으면 실제 동기화:

```bash
gdrive-sync sync
```

### GUI 로 사용하기

명령어 대신 그래픽 화면을 쓰려면:

```bash
gdrive-sync gui
```

매번 명령어 치기 번거로우면 **바탕화면 바로가기**를 만드세요 (한 번만):

```bash
gdrive-sync shortcut
```

이후에는 바탕화면의 **gdrive-sync 아이콘 더블클릭**으로 콘솔 창 없이
실행됩니다. (GUI 안에서도 가능: 도구 메뉴 → 바탕화면 바로가기 만들기)

우클릭 메뉴 방식을 선호하면:

```bash
gdrive-sync context-menu
```

> Windows 11 에서는 우클릭 메뉴 항목이 **"추가 옵션 표시"** 를 눌러야
> 보입니다 (**Shift + 우클릭**하면 바로 보임). Windows 10 은 우클릭에 바로
> 나옵니다. 이는 Windows 11 의 제한이라, 더블클릭 실행은 위의 바로가기를
> 권장합니다.

## 문제 해결

| 증상 | 해결 |
|---|---|
| `pip` 또는 `python` 명령을 찾을 수 없음 | Python 재설치하며 "Add to PATH" 체크 |
| `gdrive-sync`가 "배치 파일이 아닙니다" | 새 cmd 창에서 재시도 → 안 되면 `gdrive-sync` 대신 `py -m gdrive_sync` 사용 (밑줄 주의) |
| `No module named gdrive_sync` | 파이썬이 여러 개인 PC — `py -m pip install git+https://github.com/GYcodeAI/gdrive-sync.git` 로 재설치 |
| 설치 중 `git` 명령을 찾을 수 없음 | 1-2단계 Git 설치 |
| `credentials.json 파일이 없습니다` | 2-6단계 파일 위치·이름 확인 |
| 로그인하면 "액세스 차단됨" | 2-4단계 테스트 사용자에 본인 이메일이 추가됐는지 확인 |
| 일주일마다 재로그인 요구 | 2-7단계 앱 게시 진행 |
| 그 외 오류 | `gdrive-sync -v sync` 로 실행한 화면을 캡처해서 전달한 사람에게 문의 |
